# E資格 動く数式ノート

E資格（JDLA Deep Learning for ENGINEER）の範囲を、**数式の要点**と、**数式・図・数値が連動して動く図**でまとめたノートです。試験直前の見直しに使えるよう、文章は短く、式を中心にしています。

## 使い方

- 各ページは「要点 → 数式 → 動く図 → 試験の着眼点」の順に並んでいます。
- 動く図では、**数式の行にマウスを乗せると、図の対応する部分が光ります**。スライダーを動かすと、式に代入した数値と図が同時に変わります。
- 式を眺めて分からなかったところは、動かして確かめてください。
